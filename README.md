# Robo School

Eine responsive Website, die nach einem Figma-Design umgesetzt wurde.

## Über das Projekt

Robo School ist eine moderne Landingpage, die anhand eines vorgegebenen Figma-Mockups entwickelt wurde. 
Der Fokus lag auf einer pixelgenauen Umsetzung des Designs, responsiver Anpassung und interaktiven UI-Elementen.

## Umgesetzte Funktionen

- Responsive Design für:
  - Desktop
  - Laptop
  - Tablet
  - Mobile Geräte

- Slider-Komponenten
- Modal-Fenster
- Tabs zur dynamischen Inhaltsdarstellung
- Interaktive Elemente und Animationen

## Verwendete Technologien

- HTML5
- SCSS
- JavaScript
- Vite
- BEM Methodologie
